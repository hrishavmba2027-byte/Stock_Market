# The ONE file for everything: production pipelines, the backtesting harness,
# and the full test suite. Install into a clean venv (Python 3.10 recommended;
# 3.9 works):
#
#   pip install -r requirements.txt
#   pytest tests/
#
# Notes
# -----
# * oauth2client must NOT be installed — it causes "invalid_grant: Invalid JWT
#   Signature" with modern GCP keys. Nothing here depends on it.
# * torchvision / torchaudio are NOT listed — no module imports them, and their
#   wheels conflict with the +cpu torch build. In Docker, torch is pinned in the
#   Dockerfile before this file is processed (the range below is the floor).
# * pandas-ta and snscrape were removed (dead/abandoned); their imports are
#   guarded with try/except and all indicators are implemented natively in
#   Feature_Engineering.py.
# =============================================================================
